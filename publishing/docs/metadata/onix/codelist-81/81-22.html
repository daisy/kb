Explanation

Code 22 indicates that a publication contains audio content that is not part of an unenhanced version of the publication.

Code 22 is set in a <ProductContentType> element for digital publications since, by definition, the content is not the primary content.

Only for use in ONIX 3.0 or later.

Schema.org mapping

Code 22 is the equivalent of setting an auditory access mode using schema.org metadata.

If the additional audio does not convey information necessary to understand the publication, the auditory access mode would not apply.
