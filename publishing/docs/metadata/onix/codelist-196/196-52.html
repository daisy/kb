Explanation

Code 52 indicates that the publication can be read entirely by text, including by speech synthesis of the text or rendering on refreshable braille devices.

Code 52 is equivalent to stating that a publication has a sufficient access mode of textual.

Only for use in ONIX 3.0 or later.
