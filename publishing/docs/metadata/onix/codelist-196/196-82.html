Code List 196 - 82: WCAG v2.2

Explanation

Code 82 indicates that an EPUB publication that conforms to the EPUB Accessibility standard (version 1.1 or higher) conforms to WCAG 2.2.

This code must be paired with code 04 as well as one of the WCAG level indicators (code 84, 85, or 86).

Only for use in ONIX 3.0 or later.

Examples

Applies To

EPUB 3 EPUB 2 Audiobooks
