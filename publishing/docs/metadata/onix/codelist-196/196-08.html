Explanation

Code 08 indicates that a digital publication has not yet been assessed for accessibility or only incomplete accessibility information is provided.

The <ProductFormFeatureDescription> element can be added to explain why the accessibility of the title is not known.

Only for use in ONIX 3.0 or later.
