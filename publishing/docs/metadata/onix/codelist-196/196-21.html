Explanation

Code 21 indicates that text-to-speech playback has been optimised through the inclusion of PLS lexicons, SSML or CSS Speech synthesis hints.

These technologies are not supported, or widely supported, so setting this code is rare.

For more information, refer to the Text-to-speech section of the knowledge base.
