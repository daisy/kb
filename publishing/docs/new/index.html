What's New

This page is continuously updated to reflect significant changes to the DAISY Accessible Publishing Knowledge Base.

To closely follow changes to this site, it is recommended to watch the project's GitHub repository. If you are not interested in all the discussions that go on, you can select to watch only pull requests, as these contain the changes to the site.

Changes are listed from most recent to oldest.

August 19, 2026 — Updates for EPUB Accessibility 1.2

The EPUB Accessibility 1.2 specification is now a W3C Candidate Recommendation and will soon become a final Recommendation. The knowledge base has been updated to reflect the latest changes to the standard. In particular, the accessModeSufficient property is now required and the accessMode property is only recommended.

For more information on the standard, refer to the EPUB Accessibility page in the knowledge base.

June 29, 2026 — Image description techniques updated

The image description techniques have been updated to reflect recent changes to the recommendations in the DAISY Best Practices for Implementing Extended Descriptions in EPUB.

The use of hyperlinked descriptions remains the preferred technique, but the use of the details element is no longer recommended at this time due to support issues in reading systems.
